# 보안 · 개인정보

## 코드를 GitHub에 공개해도 되나요?

**됩니다.** 공개되는 것은 **앱 프로그램 코드**뿐입니다.

| 공개 저장소에 없는 것 | 설명 |
|----------------------|------|
| 자산·예산·거래 숫자 | 사용자 기기 + (선택) 암호화된 클라우드에만 존재 |
| 이름·이메일 | 기기마다 로컬 저장, 클라우드에 안 올림 |
| 가족 암호 | **어디에도 저장하지 않음** (입력한 기기 메모리에만) |

---

## 데이터가 저장되는 곳

1. **내 폰·PC 브라우저** (localStorage)  
2. **Firebase** (동기화 켠 경우) — **가족 암호로 암호화**된 덩어리만 저장

Firebase 관리자도 가족 암호 없이는 내용을 읽기 어렵습니다.

---

## 앱이 하는 보안 처리

### 1. 비공개(🔒) 자산
- 「배우자에게 비공개」로 표시한 자산은 **클라우드에 올리지 않습니다**
- 다른 기기에도 나타나지 않습니다 (그 기기 로컬에만)

### 2. 클라우드 암호화 (가족 암호)
- 동기화 시 **AES-GCM** 으로 암호화 후 업로드
- 가족 코드 + 가족 암호를 아는 사람만 복호화 가능
- 설정 → **가족 암호**에서 입력 (6자 이상)

### 3. 가족 코드 (6자리)
- 신규 발급 코드는 **랜덤 6자리** (읽기 쉬운 문자만 사용)
- 예전에 만든 **12자리 코드**도 입력·연동은 그대로 가능
- 추측 방지·데이터 보호는 **가족 암호**가 담당

### 4. 설정 파일 비공개
- `js/sync-config.js` (Firebase 키)는 `.gitignore` 로 커밋 제외

### 5. 기기별 잠금
- 생체 인증·앱 비밀번호·잠금 설정은 **기기마다 따로** (클라우드 미전송)

---

## 사용자가 지켜야 할 것

- **가족 코드·가족 암호**를 가족에게만 전달 (카톡·대면 등)
- 공개 Wi‑Fi에서 민감 작업 시 주의
- 브라우저 **로그아웃** 시 기기 잠금 유지
