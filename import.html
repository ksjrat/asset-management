스프레드시트 → 앱 가져오기

구글 시트에서 받은 .xlsx 파일을 앱 데이터로 변환합니다. 예산·결산·항목·계좌·부채·적금 시트를 읽으며, 거래 내역이 없는 달은 결산 시트 수치로 채웁니다.

  1. 구글 시트 → 파일 → 다운로드 → Microsoft Excel(.xlsx)
  2. 프로젝트 original data 폴더에 저장 (PC에서는 import-from-original.bat으로 변환 가능)

  4. 미리보기 확인 후 앱에 적용
