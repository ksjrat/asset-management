# 우리 자산

신혼부부를 위한 **공동 자산·예산·목표 관리** 웹앱입니다.  
앱 설치 없이 브라우저에서 쓰고, 홈 화면에 추가하면 앱처럼 사용할 수 있습니다.

## 접속 주소

PC·휴대폰·배우자 **모두 아래 주소**로 접속하세요.

**https://ksjrat.github.io/asset-management/**

> Wi‑Fi·LTE/5G 어디서든 접속됩니다. PC를 켜 두거나 같은 Wi‑Fi에 연결할 필요 없습니다.

## 시작하기

1. 위 주소를 브라우저(Safari, Chrome 등)에서 엽니다.
2. **(권장) 홈 화면에 추가**
   - **iPhone**: 공유 → **홈 화면에 추가**
   - **Android**: 메뉴 → **홈 화면에 추가** / **앱 설치**
3. **(권장) PC·폰·배우자끼리 데이터 맞추기** → 아래 [기기 연동](#기기-연동) 참고

PC에서는 화면이 넓으면 왼쪽 메뉴가 있는 PC 레이아웃으로 자동 전환됩니다.

## 기기 연동

PC·폰·배우자 기기에서 **같은 데이터**를 보려면 앱 **설정 → 연동 도우미**에서 진행합니다.

1. **같은 주소**로 접속  
   `https://ksjrat.github.io/asset-management/` (북마크·홈 화면 주소도 동일하게)
2. **연동 도우미**
   - 데이터가 있는 쪽: **코드 발급** → 카톡 등으로 **코드와 주소** 공유
   - 다른 기기·배우자: **코드 입력**
3. **가족 암호** (6자 이상, 모든 기기에서 **동일**) → **지금 맞추기**

데이터가 있는 기기에서 먼저 입력한 뒤, 다른 기기에서 도우미 마지막 단계(동기화)를 실행하세요.

## 주요 기능

| 영역 | 설명 |
|------|------|
| **홈** | 순자산·총자산·총부채 요약, 월별 추이, 재정 인사이트 |
| **자산·수익** | 자산/부채 등록, 소유 구분, 수익·저축 이력, 부동산 평가 |
| **지출** | 월별 카테고리 예산, 거래·반복 지출, 실적 입력 |
| **목표** | 공동 재정 목표, 기여 방식, 달성률·가이드 카드 |
| **메모** | 가계 관련 메모 |
| **설정** | 연동 도우미, 앱 잠금, 패치 내역 |

## 자주 묻는 것

| 증상 | 확인 |
|------|------|
| PC에서 입력한 내용이 폰에 없음 | **연동 도우미**로 기기 연동·동기화했는지, **같은 주소**인지 |
| 연동이 안 됨 | 설정에서 **클라우드: 연결됨**인지, 가족 코드·가족 암호가 모든 기기에서 같은지 |
| 화면이 예전 그대로 | 설정 → **앱 새로고침** (데이터는 유지) |

## 개인정보·보안

- 가족 암호는 **어디에도 저장하지 않습니다.**
- 클라우드에 올라가는 데이터는 **가족 암호로 암호화**됩니다.
- 「배우자에게 비공개」 자산은 **다른 기기·클라우드에 올라가지 않습니다.**
